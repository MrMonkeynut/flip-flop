# Flip-Flop To-Do

Planned features. Tick them off (`- [x]`) as they're done.

## Cleaning tools

- [ ] **Mop**: hold with two hands, and position both hands so the mop head touches the ground.
- [ ] **Sweeping brush**: same idea as the mop, but for sweeping items up instead of cleaning up spillages.
- [ ] **Dustpan and brush**: items snap into the dustpan when swept up. Shake it up and down to gently empty the items out.
- [ ] **Bins**: clean up work areas and put the rubbish into the bins.
- [ ] **Peelings**: mess that needs to be cleaned up.

## Fun stuff

- [ ] **Piñata**: hangs down, full of sweets. Can't be damaged by hands, only by hitting it with something hard.
- [ ] **Baseball bat**: hold with both hands and swing to attack.

## Systems

- [ ] **Systematic design (material properties)**: items can be set to be:
  - [ ] vulnerable to fire
  - [ ] very flammable
  - [ ] resistant to fire
  - [ ] water damageable (e.g. electrics like a TV sparking if water is dropped on it)
